A página deve ser EXCLUSIVAMENTE do HOMEM FORTE.

NÃO apresentar REX DOMINUS.

NÃO criar comparação com outros produtos.

NÃO criar produtos adicionais.

NÃO inventar ingredientes, benefícios, estudos, certificações, depoimentos, resultados garantidos, promoções ou informações que não estejam neste briefing.

==================================================

1. OBJETIVO DA PÁGINA

==================================================

Criar uma página de vendas minimalista, masculina, premium e extremamente limpa.

O objetivo é apresentar o HOMEM FORTE de forma clara e conduzir o visitante para solicitar o produto.

A experiência deve transmitir:

- simplicidade

- força

- masculinidade

- profissionalismo

- exclusividade

- segurança na compra

A página NÃO deve parecer um site genérico criado por IA.
